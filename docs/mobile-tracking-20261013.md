# 手机端提交与问题追踪体验

日期：2026-10-13。状态：**待体验**。本地实现、适用自动检查与真实浏览器核验已完成；未提交、发布或部署。

## 可以体验的变化

- **T1 提交后的下一步**：服务确认接收后展示保存回执、反馈编号和「查看进展」，直接打开刚提交的问题；「再记一条」恢复编辑。Web 成功页收起空白描述和附件表单。后台整理、人工归档或整理失败仍单独说明，归档不代表问题解决；已接收反馈的状态刷新只读，不重复提交。
- **T2 问题追踪**：「我的反馈」显示多行标题、问题状态、新动态、准确的管理员／系统／本人角色、动态数量和最近更新时间，提供状态筛选、分页和刷新。详情呈现完整标题、编号、下一步指引，以及原文、回复和处理说明组成的纵向时间线。解决后仍能补充，补充进入原问题并重新等待管理员回复，保留原 Kaneo 工单。
- **T3 手机上的持续沟通**：Web 与 Flutter 按问题保留当前会话里的补充文字、图片和日志；返回列表、切页签或关闭重开不会静默丢弃。发送按问题防重复，允许离开，迟到结果不清掉其他问题的草稿。慢速详情请求不会被十秒轮询不断覆盖。Web 短屏固定发送操作；高度极低时改为整个详情可滚动。Flutter 提供可定位补充区的底部入口。

顺带修复了实测阻塞：新登录响应补齐能力声明，使 Web 纯文字提交后立即显示追踪入口；Flutter 在 MaterialApp 外侧挂载、系统语言为中文时，使用受现有默认委托支持的兜底语言，修复输入框空白和本地化异常。中文业务文案保留，未新增依赖。
