# 网页后台 UI 与使用体验优化

日期：2026-10-13。状态：**待体验**。已完成本地实现与适用验证，尚未部署。

## 可以体验的变化

- T1 界面与导航：沿用现有蓝白、深色主题，统一品牌、页头、筛选面板和表格层次；侧栏底部展示当前身份。手机端通过完整菜单访问七个后台页面，支持键盘焦点与关闭恢复。账号、软件等宽表格保留阅读宽度并提示横向滑动；手机新建账号表单改为纵向填写。
- T2 反馈处理：处理状态与工单状态分别标注，显示已生效筛选、逐项移除和一键清除；清除时取消尚未执行的搜索防抖。筛选无结果与请求失败分别提示。未发送回复、分类草稿在关闭抽屉前确认，提交中保持现场；对话读取失败可原地重试，重试保留输入，迟到响应不会覆盖当前对象。
- T3 软件配置：切换软件、新增和取消编辑前检查未保存草稿；取消保留、确认后再切换。详情加载时冻结编辑与保存。列表加载、失败、真正空态分别显示，失败可重试。同对象刷新继续保留原有草稿规则。
- T4 账号与系统：密码重置掩码输入，失败在弹窗内提示并保留原值，提交中防重复和误关闭；重置成功后的列表回读失败仅重试 GET。修正凭据变更说明，系统更新初次加载失败提供重试，长配置值在窄屏换行。
