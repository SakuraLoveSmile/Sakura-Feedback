## 用户澄清与已确认决定

- 0.8.2 的实现：选中“隐藏”后 `canUseOrbLauncher()` / `_launcherVisible` 直接判 false，灵感球整体不渲染且唤醒手势失效，只能靠宿主入口打开面板。
- 正确语义：**只隐藏待机（闲置 5 秒后收起）状态**。默认仍先显示完整球；闲置 5 秒后不显示小把手/贴边球等任何收起入口；已开启的唤醒手势仍能唤醒完整球，唤醒后可点击/拖动继续使用；再次闲置 5 秒重新隐藏。未开启手势时仍可由宿主入口打开面板并改回其他样式。
- 0.8.4 宿主托管模式（Flutter `orbIdleStyle` / `wakeGestures`）同样适用：宿主传入 `hidden` 时行为一致，宿主改回 handle/edge 后恢复对应待机形态。
- 偏好与编解码保持兼容：`feedback:orb-idle:v1:<appId>` 的 `hidden` 值不变，旧版组件读到仍回退 `handle`。

## 实现要点

- Web（基于 0.8.3 基线重新移植）：`canUseOrbLauncher()` 去掉 hidden 早退；新增 `.fb-orb.is-idle-hidden`（display:none）并在 `setOrbCollapsed`/`syncOrbIdle`/偏好加载时同步；`drawLiquid()` 在待机隐藏时同时收起球体 canvas 与 outline 兄弟层；`canWakeOrb()` 在隐藏待机时仍可用；手势 `wakeOrb()` 恢复完整球并重启 5 秒闲置计时；设置与 `docs/integration.md` 文案同步。
- Flutter（基于 0.8.4 宿主托管结构适配）：`_launcherVisible` 恢复为只看 `showLauncher`；新增 `_orbIdleHidden`（使用生效的 `_orbIdleStyle`，宿主托管时同样生效）并在 build 时不渲染 launcher slot；`_wakeAvailable` 不因 hidden 失效；`_wakeOrb()` 从待机隐藏唤醒时 morph 归零让完整球立即可用，再闲置后重新隐藏；`_lensVisible`/焦点环/拖动回弹状态适配；设置与 Flutter README 文案同步。
- 版本与文档：root/server/admin/Web/Flutter 统一 **0.8.5**；Flutter 示例 path 包锁定版本同步；README/接入文档版本引用更新；新增本记录与 `CHANGELOG.md` 段落。
