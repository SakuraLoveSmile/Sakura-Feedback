## 第一阶段 · 收件箱与反馈处理

| 操作 | 优化前的实测现象 | 现在的体验 |
| --- | --- | --- |
| 浏览桌面收件箱 | 1440px 视口下，空详情占 440px，列表只有 684px，软件和账号列也被隐藏 | 未选择时列表可用宽度为 1140px；选中后再分栏，当前条目有左侧标记，批量勾选独立显示 |

## 第二阶段 · 登录与八个管理页面

沿用项目组件、浅深主题和分区导航。扩展范围覆盖管理登录、反馈详情、收件箱、更新日志、软件配置、账号、连接配置、会话、管理员设置和系统更新，保持服务端契约与数据结构。桌面采用深蓝色侧栏，手机保留分组菜单，表格与编辑器根据可用宽度重排。

| 原有操作障碍 | 已实施的处理与验收场景 |
| --- | --- |
| 编辑过程中点击菜单或后退会离开表单 | 反馈回复、软件、账号、日志、连接和管理员设置登记表单修改。菜单和退出可以取消放弃，浏览器后退取消后恢复原条目，刷新可使用浏览器原生提示。 |
| 反馈筛选需要逐项展开 | 收件箱增加「待管理处理」快捷筛选，区域标签支持方向键及 Home、End。桌面详情与列表并排，手机搜索常驻。 |
| 手机上需要横拖表格查软件、改额度或找会话 | 软件、账号、会话在窄屏展示带字段名的逐条卡片，支持搜索与清除，并能分别按配置状态、启用状态、会话类型筛选。软件配置按钮定位到编辑区。空白额度提示修正。撤销会话显示具体设备或数量。 |
| 编写日志时难以及时看效果，取版本失败时仍可能显示空表单 | 编辑器可就地预览，保存操作跟随滚动。切换软件或版本前保护未保存编辑。读取失败单独重试，恢复后再开放编辑。 |
| 一组连接失败会影响另一组，改了地址仍能测试旧配置 | Kaneo 和 AI 分别读取、重试、保存和测试。保存成功再允许测试，留空密钥沿用已保存值。 |
| 会话读取故障和退出故障容易被当成登出，管理员设置与系统检查可能造成误判 | 登录区显示服务地址与密码显隐，区分普通账号和管理员。退出失败保留工作区。管理员设置仅在凭据变化后可提交。系统更新区分已关闭、服务报错与检查成功，可复制服务器更新命令。 |
