### R7.2 内部材质与安全边界

- 复用同一张已遮挡安全纹理；禁止BackdropFilter、CSS backdrop-filter或新的实时背景读取，装饰材质继续不调用宿主正式截图provider。handle不再被当作不显示材质的状态，但真实隐藏、面板/捕获/选区、后台、身份或尺寸失效仍执行原有释放/失效规则，保留generation、单在途、取消与图片所有权。
- Web的`OrbLens.draw`在现有参数后增加可选内部材质对象；Flutter在原18个float后统一追加：halfSize.x[18]、halfSize.y[19]、handleMix[20]、mist[21]、idleMix[22]，共23float。现有前18槽顺序不变；默认halfSize=(radius,radius)，其他新增值为0，因此原R3调用与选区交接保持清晰材质。常态入口显式传idleMix=1、mist=.74；拖动/选区使用0；halfSize与handleMix在420ms过渡内插。
- 胶囊几何：stem=max(0,halfSize.y-halfSize.x)，capsuleOffset=(delta.x,delta.y-clamp(delta.y,-stem,stem))，capsuleR=length(capsuleOffset)/halfSize.x；handleMix在原球r和capsuleR之间混合。折射offset同样混合delta/capsuleOffset，源点为p+offset*(bend-1)，让直边保持竖直；handle半宽6、半高28。halfSize.x控制把手约.55px的高光宽度，不能把圆球的归一化细边直接缩到看不见。
- 模糊使用同一safe sampler的有界5×5高斯近似，逻辑偏移{-10,-5,0,5,10}，每轴权重{.05449,.24420,.40262,.24420,.05449}；仅mist>0时采样并与原色混合。每个样本沿现有半像素钳制和Flutter GLES坐标规则；Flutter先平均预乘RGBA，再按已有方式解预乘着色，输出继续预乘。不得用无上限循环或额外常驻背景副本。具体局部函数组织可自主处理，改变此共享语义须先同步主agent。

透明图层须与原全画布结果等价并保持预乘alpha：有纹理时，令 `i=inside`、`aGlow=g*(1-i)*(1-i)`，输出 `rgb=(glass*i+glowColor*aGlow)*opacity`、`alpha=(i+aGlow)*opacity`。这对应原版先按 `g*(1-i)` 混合外光、再按 i 混合玻璃；无纹理时只使用现有安全细边/外光降级，不能输出整块不透明填色。深浅色均保留原≥.85内部文字对比度门槛。

上式的参考背景完全不透明。Flutter 既有半透明输入契约仍保留：若安全快照自身带alpha，玻璃贡献使用 `surfaceAlpha=i*base.a`（外光独立），RGB按各采样点原alpha解预乘后着色，再按surfaceAlpha预乘输出；不能把透明/半透明宿主强行变成不透明黑底，也不能把既有128/64的像素断言改成255/128来迁就实现。

### 2. 两端统一光学

全部几何使用逻辑像素；捕获图像纹理具有单独的 pixelRatio。DPR上限2，捕获长边≤2048、总像素≤4,000,000、PNG≤5MiB，继续遵守现有更严格约束。

`R` 是当前状态半径，活动态为52；放大倍率 `magnification=1.62`，液态系数 `liquid=1`，边缘强度 `rimStrength=.52`。设球心 `c`、逻辑像素位置 `p`、极角θ、径向单位向量 `n=(cosθ,sinθ)`、切向向量 `t=(-sinθ,cosθ)`，二/三/四阶形变为二维向量m2/m3/m4：

```text
area = 1 / sqrt(1 + (|m2|² + |m3|² + |m4|²) / 2)
contour = area * (1 + dot(m2,[cos2θ,sin2θ])
                   + dot(m3,[cos3θ,sin3θ])
                   + dot(m4,[cos4θ,sin4θ]))
slope = d(contour)/dθ
normal = normalize(n - t * slope / contour)
r = |p-c| / (R * contour)
aa = 1.1 / R
inside = 1 - smoothstep(1-aa,1+aa,r)
outward = mix(r/1.62,1.18,smoothstep(.64,.86,r))
folded = mix(1.18,.62,smoothstep(.86,1,r))
sourceRadius = r < .86 ? outward : folded
source = c + n * R * contour * sourceRadius
dispersion = .68 * smoothstep(.75,.98,r)
```

RGB分别采样 `source+normal*dispersion`、`source`、`source-normal*dispersion`（与冻结预览第210行的通道方向一致）。这使 `.86R→1R` 的源半径从 `1.18R` 回落到 `.62R`，形成边缘的反向倒影；不得改回单调倍率，也不得用静态亮环冒充倒影。球心方向未定义时取安全径向(1,0)，source仍为球心。纹理坐标钳制到可用半像素边界，不采样未初始化区域。

```text
light = .5 + .5*dot(normal,normalize([-.6,-.8]))
rim = exp(-((r-.993)/.010)^2)
inner = exp(-((r-.85)/.025)^2)
caustic = exp(-((r-.79)/.07)^2) * (.5+.5*normal.y)
shadow = exp(-((r-.978)/.012)^2) * (1-light)
glass *= 1-shadow*.10
whiteMix = rim*(.16+.40*light)*.52 + inner*.045*light + caustic*.065
outerGlow = exp(-((r-1.025)/.045)^2)*.035
```

采样色保持透明玻璃观感；以 inside 输出抗锯齿透明轮廓，轮廓外仅允许上述微弱外光。不得叠旧不透明中心填充。绘制盒预留至少1.6R半径以容纳所有模式叠加与外光；旧圆/椭圆Clip不能裁掉高阶形变。Flutter输出须符合premultiplied alpha，Web须明确WebGL混合与颜色空间处理，视觉以参考为准。

**统一 uniform 契约（Flutter float 索引；Web相同语义）**：

| 槽位 | 名称 | 单位与意义 |
| --- | --- | --- |
| 0–1 | uImageSize | 捕获图实际像素宽高 |
| 2–3 | uOffset | 绘制盒左上角相对捕获视口原点的逻辑坐标 |
| 4 | uScale | 捕获像素 / 逻辑像素，不是屏幕DPR的盲目拷贝 |
| 5–6 | uCenter | 球心相对捕获视口原点的逻辑坐标 |
| 7 | uRadius | 当前逻辑半径 |
| 8–9 / 10–11 / 12–13 | uMode2 / uMode3 / uMode4 | 无量纲二维形变 |
| 14 / 15 / 16 | uMagnification / uRimStrength / uOpacity | 1.62 / .52 / [0,1] |
| 17–18 | uLocalSize | 绘制盒逻辑宽高；Web用于gl坐标转换，Flutter可保留未使用槽位 |

### 3. 两端统一动力学

固定积分步长 `1/240s`；每帧真实dt最多`.05s`；只在拖动、尚未收敛或过渡中安排RAF/Ticker，不维持空转。预览慢放`.25×`只缩模拟时间，不减形变幅度，生产不暴露慢放按钮。

```text
v += ((target-pos)*440 - v*28)*dt
pos += v*dt
strain = moving ? clamp(speed/1050 + lag/220,0,.27) : 0
angle = atan2(vy,vx)
mode.v += ((modeTarget-mode.pos)*frequency² - mode.v*damping)*dt
mode.pos += mode.v*dt
```

| 模式 | modeTarget | frequency | damping | 幅度上限 |
| --- | --- | ---: | ---: | ---: |
| 2 | strain * (cos2a,sin2a) | 19 | 9.5 | .34 |
| 3 | -.40*strain * (cos3a,sin3a) | 13 | 6.8 | .13 |
| 4 | .85*strain² * (cos4a,sin4a) | 26 | 10 | .06 |

到达幅度上限时径向钳制，移除继续向外的速度分量；停止条件同时满足位置误差<.02px、速度<.1px/s、各mode幅度<.0005、mode速度<.003。drag的target是经过现有命中偏移处理后的实际指针目标；提交releasePoint只用实际最后指针，不用惯性球心。取消/新拖动/身份变动清理残留速度和调度。

Reduced motion：位置直接到target，速度/mode归零，尺寸及流程直接切到各关键静态状态；仍提供真实采样和选区，不通过禁用反馈功能来降低动画。forced-colors复用清晰系统色轮廓与焦点，无需WebGL但所有操作可用。

### 4. 拖动时的透镜纹理与隐私

选择**独立、只在本地显示、经过遮挡的一次性装饰快照**。Web复用 `captureViewport` 内置遮挡管线，不为装饰调用宿主captureProvider；真实截图仍在松手调用原provider并传最终releasePoint。这样不会改变宿主provider的调用时机/次数/参数约定。

- 首次可见且orb模式启用后可预取一次；拖动开始时仅在纹理缺失/失效/距上次快照≥1000ms时按需刷新。单在途，无定时轮询，无每帧重捕获。
- Web只使用内置管线输出的已遮挡blob解码后上传纹理；不可直接抓未遮挡DOM进入WebGL。捕获自身UI用现有clone排除，不为装饰快照闪烁面板或改captureSeq。
- Flutter抽出 `_captureFrozen` 的已遮挡前半段供装饰快照复用，保持独立generation与单在途标志，不能通过借用真实captureSeq取消正在进行的业务捕获。遮挡几何必须在同一捕获阶段固定；mask填充不透明；不增加PNG编码。
- 快照仅显示捕获时内容，宿主动态内容可能在一次拖动内陈旧。这是已选定的性能取舍；松手后的正式截图仍新取。不宣称实时视频/PlatformView能透镜显示。
- 视口尺寸/DPR、身份、controller、宿主重新挂载、page变更使纹理失效；滚动时失效且不自动重复捕获。隐藏/离开/关闭时释放图片、GL纹理、ImageBitmap、URL、回调与Ticker。
- shader/快照失败、不可捕获跨域或PlatformView时退为无采样玻璃轮廓，真实截图仍走原失败与重试提示；禁止使用未经遮挡的BackdropFilter旁路。无采样降级不算视频效果已通过。
- Flutter边界可处在非(0,0)：所有releaseGlobal与透镜offset先 `boundary.globalToLocal`，再归一化；不得直接global坐标除boundary尺寸。

### 5. 球转选区

选区固定从最终指针落点为中心的48×48开始，边缘处整体clamp进捕获视口；最小边长48，视口不足48时取实际尺寸。确认界面在正式截图准备好后才出现，不用旧装饰纹理作为用户证据。

| 项 | 相对选区出现的时间与数值 |
| --- | --- |
| 球到方框的轮廓 | 0–400ms；半径52→12，尺寸从104×104到48×48；起点优先用松手时可见球心，终点为实际落点的clamped框 |
| 球图层淡出 | 0–260ms |
| 选区框淡入 | 50–300ms |
| 画面遮罩 | 0–350ms；色#635d92、alpha .26，选区内保留原画面 |
| 关闭按钮 | 120–400ms出现；独立右上角，粗指针命中≥44px |
| 工具条 | 350–550ms出现；238×40px（粗指针高48），圆角14，距框14px，优先上方，空间不足下方，整体clamp至少8px视口边距 |
| 角点 | 四个可见角，白色2px角标，命中30px，粗指针44px；不得遮住工具条 |
| 操作 | 框内拖移、框外重新画、四角缩放；方向键6px、Shift+方向键缩放6px、Enter确认、Esc取消、Tab焦点锁 |

工具条两项：“调整截图”（状态文字）与蓝色 `#0071e3` 的“使用此区域”。“截取整个窗口”保留为工具条下方的次级文字按钮（整行可命中，高≥32/44px，不挤进238px主条）；“取消”由独立关闭按钮提供，同样有明确可访问标签。旧8个控制点的几何函数可保留，UI只显示4个角点；键盘缩放保留。极窄/角落布局要clamp工具区并避免角点命中重叠，允许工具条固定在视口顶部8px作为确定性空间不足策略。

捕获时窗口大小与DPR作为session的一部分；调整期间变化就取消旧session并提示重新截图，不拉伸旧冻结图然后提交错误region。crop.region、viewport、pixel尺寸保持原公开契约；裁剪失败仍停留选区，整窗入口省略region。

### 6. 确认后进入真实反馈面板

用户点击后先锁确认并准备裁剪/编码；以下时间原点是“图片准备成功、会话有效、开始交接”的时刻，避免慢设备图未准备好先播放。通过原提交函数更新一次草稿与真实附件DOM/Widget，保留相同附件ID的原位替换规则。目标位置从**真正被新增/替换的附件缩略图**测量，不能总飞到第一格，也不能使用预览固定坐标。

| 动画 | 时间 / 参数 |
| --- | --- |
| 遮罩背景模糊 | 0–350ms，0→3px；只处理冻结画面，不对宿主实时敏感内容加BackdropFilter |
| 面板透明度 | 60–300ms，0→1 |
| 面板上移 | 120–1050ms，translateY104%→0，保留当前宽度/锚点/响应式布局 |
| 截图飞行 | 180–1330ms，从所选屏幕rect到最终附件rect；位置/尺寸插值，额外y偏移 `-12*sin(pi*p)` |
| 飞行图圆角与影子 | 12→10；shadowY=`16*sin(pi*p)`、blur=`30*sin(pi*p)`、alpha=`.2*(1-p)` |
| 交接图与真实附件换位 | 1220–1350ms，交接图淡出、附件显现，不能双影常驻 |
| 可交互与焦点 | 1350ms解除面板禁用；1500ms结束，聚焦原描述输入；球在全程隐藏 |

所有上述进度使用 `smoothstep(p)=p²*(3−2p)`，p先clamp[0,1]。目标rect在面板最终布局态测量，再施加入口动画；避免测到translateY104%时的屏外位置。必要时一次post-frame/layout回调测量，必须再核对session代数。

面板常驻，Flutter稳定Key与槽位，避免条件分支改变导致Element重排断言。冻结图片和飞行图片具有单一所有者；正式图片被草稿采用后，视觉层保留独立引用/解码对象到动画完成，`finally`不能提前dispose。缺少目标可见rect（例如用户切tab/关闭）时取消飞行并落到已存在的真实附件；不制造假缩略图。关闭/身份/尺寸失效的generation检查覆盖所有await、post-frame、RAF/Ticker完成回调。Reduced motion直接显示完成态并聚焦，不等待1500ms。
