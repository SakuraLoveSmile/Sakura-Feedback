## 目标

两端（Flutter SDK + Web 组件）默认入口改为「双指长按 → 从按压点扩散的水波纹 → 压暗 → 画圈成方框 → 现有选区工具条 → 面板」，波光作为可选项。灵感球降级为终端用户在面板设置中可切换的样式；默认无驻留入口，鼠标/键盘依赖可配置快捷键与无障碍隐藏入口。

## 已确认决定

1. 两端同时落地，行为与视觉契约一致。
2. 默认触发双指长按（700ms）。
3. 圈选：包围盒 +8px、最小 64px，复用现有选区工具条。
4. 唤醒视觉默认水波纹，可切换为波光。水波从两指中间起一圈并向四周发散，波光在双指各自的位置起亮，720ms 后进入圈选。
   当前造型见 [共享动效规格](../beam-spec.md#2-唤醒动效时序与颜色)。波光以用户视频为参考，水波纹以 PKG110 的充电水波为参考。
5. 默认开启视口截图（`capture-mode=viewport`），显式 off 仅打开纯表单。
6. 快捷键默认 Primary+Shift+F，可配置/关闭；补视觉隐藏的可聚焦入口。
7. 用户偏好 key：`feedback:launcher-style:v1:<appId>`，仅在宿主 `launcher-mode=beam` 时可切换。
